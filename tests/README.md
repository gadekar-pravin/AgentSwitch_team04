# Hand-written tests

Graded tests go here, written by team members. Tests generated by Claude or Codex score zero, so nothing in this folder was written by an AI.

Run with `python -m pytest tests`.

Useful building blocks:
- `prod_agent.domain`: `diagnose`, `downstream_impact`, `propose_reschedule`, `apply_proposal`, with no LLM involved.
- `prod_agent.mcp_client.McpClient(Session("suryodaya"))` for live calls. `RestClient` for independent reads.
- `harness.fixtures.late_draft_chain(mcp)` for rows the team owns and may write to.
